Power BI QA

Automated Power BI Data Validation Framework

Challenge: Business teams depended on Power BI dashboards for decision-making, but regression testing was manual, slow, and difficult to trust. Reports had to be opened one by one, KPI values checked visually, and numbers compared to warehouse queries by hand.

Role: QA Lead responsible for framework design, validation strategy, and team delivery.

Python Playwright Snowflake dbt SQL YAML CI/CD Claude Code
30+ reports validated in under one hour with repeatable, auditable results.

Problem

Dashboards can look correct while still showing wrong numbers. Manual validation was too slow and too inconsistent for a business-critical reporting layer, and it created a real risk of invalid decisions being made from the wrong KPI values.

Solution

  • Built a reusable, configuration-driven QA framework that validates reports across UI, data, and business-rule layers.
  • Used Playwright to extract values displayed to users, including KPI cards, chart categories, and table rows.
  • Recomputed expected values directly from Snowflake and dbt logic based on the report’s reporting date to prevent refresh drift.
  • Implemented tolerance-aware comparisons for single values, grouped charts, and detail tables using composite keys.
  • Added business-rule checks for negative counts, percentage totals, missing controls, and duplicate keys.
  • Created ETL-level validation checks for source data integrity before report-level testing began.
  • Integrated the framework into CI/CD so every run produced Excel, JSON, HTML, screenshots, and SQL-based root cause output.

Why it mattered

Reliable decision support

Reports were tested against both what users see and what the warehouse says — the combination required for trustworthy BI.

Faster regression cycles

Validation moved from a two-day manual process to a repeatable under-one-hour automation workflow.

Scalable framework

New reports were added via configuration rather than custom framework changes, making the solution easy to extend.

AI-assisted delivery

Claude Code accelerated scaffolding and refactoring, while QA strategy and acceptance criteria remained human-owned.

Outcome

  • 30+ Power BI reports covered by automated regression testing.
  • Regression validation time reduced from approximately two days to under one hour.
  • Repeatable, auditable results built into every pipeline run.
  • A long-term QA framework for data quality and decision support at scale.
“The strongest BI validation model checks both sides: what users see and what the data says.”
