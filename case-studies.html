Power BI QA

Automated Power BI Data Validation Framework

Challenge: Business teams relied on Power BI dashboards for decisions, but regression testing was manual. Testers had to open each report, read KPI values, compare them against warehouse queries, and validate dozens of visuals by hand. The cycle lasted around two days for 30+ reports and made it easy to miss subtle data issues.

Role: QA Lead, framework architecture and delivery.

Python Playwright Snowflake dbt SQL YAML CI/CD Claude Code
30+ reports validated in under one hour with repeatable, auditable results.

Problem

Manual report validation creates a critical trust gap: dashboards can render correctly but still reflect the wrong numbers. A visual check alone proves the report displayed a value; it does not prove that value matches the business truth in the warehouse. The QA process had become slow, costly, and inconsistent.

Solution

  • Built a reusable, configuration-driven validation framework that validated reports across multiple layers.
  • Used Playwright to extract values users actually see in the browser: KPI cards, chart categories, and table/matrix rows.
  • Recomputed expected values in Snowflake with SQL tied to each report’s specific “Data As Of” date to eliminate refresh drift.
  • Added tolerance-based comparisons for single values, grouped charts, and table data using composite keys.
  • Embedded business-rule checks such as no negative counts, percentages summing to 100, and no duplicate keys.
  • Added separate ETL-level checks for missing keys, duplicates, and null control fields before a report was ever trusted.
  • Deployed the framework in CI/CD with parallel execution and generated HTML, JSON, Excel, screenshots, and root-cause SQL outputs for every failed validation.

Why this mattered

Config over code

New report coverage was added through YAML definitions and SQL files rather than custom framework changes.

Fail loudly

If a reporting date or calculation context couldn’t be resolved, the check failed with a clear reason instead of silently passing.

Layered validation

UI validation proved the value was displayed; source reconciliation proved the value was correct.

AI as accelerator

Claude Code accelerated scaffolding and refactoring without replacing human-owned QA decisions or acceptance criteria.

Results

  • 30+ Power BI reports under automated regression validation.
  • Regression validation reduced from roughly two days to under one hour.
  • Results became repeatable, auditable, and extendable across the business.
  • The framework supported both data correctness and user-facing report quality.
“The right BI testing model checks both sides: what users see and what the warehouse says.”
