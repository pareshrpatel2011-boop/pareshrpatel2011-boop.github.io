Featured Project

Automated Power BI Data Validation Framework

Business-critical dashboard testing, automated end to end.

Built a reusable, configuration-driven QA framework that validated Power BI outputs against warehouse logic and browser-rendered data using Python, Playwright, SQL, Snowflake, dbt, and CI/CD.

1. UI extraction

Playwright opened each report in a real browser and read displayed KPI cards, chart values, and table rows to validate what end users actually saw.

2. Data reconciliation

SQL recomputed the expected numbers in Snowflake using each report’s own “Data As Of” date, preventing mismatches caused by data drift during refresh cycles.

3. Tolerance-based comparison

A Python comparator matched single values, grouped chart output, and tables using composite keys, returning PASS, WARNING, or FAIL based on configured tolerances.

4. Business and ETL checks

The framework caught negative values, percentage mismatches, duplicate keys, null control fields, and missing data before they reached business users.
